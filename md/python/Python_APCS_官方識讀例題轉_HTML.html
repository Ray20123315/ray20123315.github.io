第 1 題

1. 題目

給定下列函式 f()，當執行 f(10) 時，最終回傳結果為何？

def f(i):
    if i > 0:
        if (i // 2) % 2 == 0:
            return f(i - 2) * i
        return f(i - 2) * (-i)
    else:
        return 1
  1. 1
  2. 3840
  3. -3840
  4. 執行時導致無窮迴圈，不會停止執行
2. 解析（點擊後顯示）

每次遞迴都讓 i 減少 2，因此呼叫順序為：

f(10) → f(8) → f(6) → f(4) → f(2) → f(0)

f(0)=1。再由內往外乘回來：

f(2)  = 1 × (-2)
f(4)  = (-2) × 4
f(6)  = (-8) × (-6)
f(8)  = 48 × 8
f(10) = 384 × (-10)

共有三個負因數：-2、-6、-10，所以結果為負。

答案：C，-3840。

整數列表滿足 a[k] = 3k + 1，索引為 0～99。以 value=100 呼叫以下函式，兩個 while 主體分別執行幾次？

def f1(a, value):
    r_value = -1
    i = 0
    while i < 100:
        n1 += 1
        if a[i] == value:
            r_value = i
            break
        i = i + 1
    return r_value

def f2(a, value):
    r_value = -1
    low = 0
    high = 99
    while low <= high:
        n2 += 1
        mid = (low + high) // 2
        if a[mid] == value:
            r_value = mid
            break
        elif a[mid] < value:
            low = mid + 1
        else:
            high = mid - 1
    return r_value

二分搜尋的中點依序為：

49 → 24 → 36 → 30 → 33

共 5 次找到。

原程式無法正確列印 20 次 Hi!。下列哪個修改仍無法列印 20 次？

for i in range(0, 101, 5):
    print('Hi!')
  1. 改為 range(0,20,1)
  2. 改為 range(5,101,5)
  3. 改為 range(0,100,5)
  4. 改為 range(5,100,5)
2. 解析（點擊後顯示）

逐一計算：

range(0,20,1)   → 0～19，共 20 次
range(5,101,5)  → 5～100，共 20 次
range(0,100,5)  → 0～95，共 20 次
range(5,100,5)  → 5～95，共 19 次

答案：D。

第 27 題

1. 題目

執行下列函式時，哪一行永遠不會被執行？

def F(a):
    while a < 10:
        a = a + 5

    if a < 12:
        a = a + 2

    if a < 11:
        a = 5
  1. a = a + 5
  2. a = a + 2
  3. a = 5
  4. 每一行都有可能執行
2. 解析（點擊後顯示）

while 結束時一定有 a >= 10。

若此時 a 是 10 或 11，第二段 if 會再加 2，變成 12 或 13；若本來已經至少 12，則保持不變。

所以到最後一個 if 時，a 一定至少為 12，a < 11 永遠不成立。

答案：C，a = 5。

第 28 題

1. 題目

下列函式執行後回傳的 x 為何？

def F(n):
    x = 0
    for i in range(1, n + 1):
        for j in range(i, n + 1):
            k = 1
            while k <= n:
                x = x + 1
                k = k * 2
    return x
  1. n(n+1)√⌊log₂n⌋
  2. n²(n+1)/2
  3. n(n+1)(⌊log₂n⌋+1)/2
  4. n(n+1)/2
2. 解析（點擊後顯示）

前兩層迴圈的總次數為：

n + (n-1) + ... + 1 = n(n+1)/2

內層 while 的 k 為 1,2,4,8,...，因此執行：

⌊log₂n⌋ + 1

兩者相乘：

n(n+1)(⌊log₂n⌋+1)/2

答案：C。

第 29 題

1. 題目

下列程式想找出最大值 M 與最小值 N。哪一組初始列表可以測出程式有誤？

M, N, s = -1, 101, 3

for i in range(s):
    if A[i] > M:
        M = A[i]
    elif A[i] < N:
        N = A[i]
  1. [90,80,100]
  2. [80,90,100]
  3. [100,90,80]
  4. [90,100,80]
2. 解析（點擊後顯示）

錯誤原因是使用 elif：只要元素更新了最大值，就不會再檢查它是否也是目前最小值。

若列表嚴格遞增：

[80,90,100]

每個元素都會進入第一個 if，N 永遠維持 101，明顯錯誤。

答案：B。

第 30 題

1. 題目

下列程式輸出為何？

a = [0] * 101
b = [i for i in range(101)]

for i in range(1, 101):
    a[i] = b[i] + a[i - 1]

print(a[50] - a[30])
  1. 1275
  2. 20
  3. 1000
  4. 810
2. 解析（點擊後顯示）

a[i] 是 1 到 i 的前綴和：

a[50] = 1+2+...+50
a[30] = 1+2+...+30

兩者相減後，剩下 31 到 50：

31+32+...+50

共有 20 項，平均值是 (31+50)/2=40.5，所以總和為：

40.5 × 20 = 810

答案：D，810。
