## 建議的學習循環

**讀原理 → 手算範例 → 自己輸入程式 → 編譯與測試 → 獨立解一道變化題。**

正式參賽的解題語言、編譯器版本、題目形式及考場限制，請以你報名的那一屆學校或賽區正式公告為準。
