# 18. Greedy：貪心法

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

貪心是每一步選看似最好的方案，但只有能證明「局部最佳不會失去全域最佳」才能安全使用。

## 2. 必要規則與語法

活動安排題可以先依結束時間排序，再選擇與上一活動不衝突、最早結束的活動；最早結束可以留最多空間給之後活動。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<std::pair<int,int>> a(n);
    for (int i = 0; i < n; i++) {
        int start, end;
        std::cin >> start >> end;
        a[i] = {end, start};
    }
    std::sort(a.begin(), a.end());
    int lastEnd = -1, count = 0;
    for (auto p : a) {
        if (p.second >= lastEnd) {
            count++;
            lastEnd = p.first;
        }
    }
    std::cout << count << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

活動 (1,3)、(2,5)、(3,4)、(4,6) 可選 (1,3)、(3,4)、(4,6)，共 3 個。假設時間非負。

## 5. 驗證：先預測，再執行

輸入 `4↵1 3↵2 5↵3 4↵4 6`，應輸出 3。

## 7. 常見錯誤

不是所有最佳化問題都能用貪心，請先驗證選擇依據。
