# 07. vector：一次儲存多個數字

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

要儲存 100 個分數，使用 100 個獨立變數不合理；vector 就像一排有編號的置物櫃。

## 2. 必要規則與語法

`vector<int> a(n)` 有 n 個整數，合法索引為 0 到 n-1。`a[i]` 取得第 i 個元素，`a.size()` 是長度。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<int> a(n);
    for (int i = 0; i < n; i++) std::cin >> a[i];
    int best = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > best) best = a[i];
    }
    std::cout << best << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

資料 3、7、2、9、4：best=3→7→7→9→9，最大值 9。本例要求 n≥1。

## 5. 驗證：先預測，再執行

輸入 `5↵3 7 2 9 4` 得 9；輸入 `3↵-5 -2 -8` 得 -2。

## 8. 常見錯誤

不能存取 `a[n]`，因為最後一格是 `a[n-1]`。
