# 05. for、while：重複執行

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

想加總 1 到 100，不用貼上 100 次加法，因為重複性操作可由迴圈完成。

## 2. 必要規則與語法

`for (初始化; 條件; 更新)` 適合已知次數；`while (條件)` 適合未知次數。更新必須朝離開迴圈的條件前進。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    std::cout << sum << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

n=4：sum 由 0→1→3→6→10；`i++` 讓 i 每輪加 1，`sum += i` 是 `sum=sum+i` 的縮寫。

## 5. 驗證：先預測，再執行

輸入 4 應輸出 10，輸入 0 應輸出 0。

## 7. 原始延伸練習

⭐ 輸出 1 到 n 的偶數，並試著用 while 重寫。

??? tip "只在卡住時展開"
    先寫出「輸入 → 變數如何改變 → 預期輸出」，再改寫程式並自行執行。不要只複製解答。

## 8. 常見錯誤

`i<n` 和 `i<=n` 的執行次數不同；忘記更新變數可能變成無窮迴圈。
