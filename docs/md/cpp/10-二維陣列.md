# 10. 二維陣列與矩陣

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

棋盤、地圖與成績表是「列 × 欄」的資料，二維 vector 能自然描述它們。

## 2. 必要規則與語法

`vector<vector<int>> a(r,vector<int>(c))` 表示 r 列 c 欄。`a[i][j]` 對應第 i 列第 j 欄。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>
#include <vector>

int main() {
    int r, c;
    std::cin >> r >> c;
    std::vector<std::vector<int>> a(r, std::vector<int>(c));
    long long sum = 0;
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            std::cin >> a[i][j];
            sum += a[i][j];
        }
    }
    std::cout << sum << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

2×3 矩陣的 6 個數字 1、2、3、4、5、6，總和為 21。

## 5. 驗證：先預測，再執行

輸入 `2 3↵1 2 3↵4 5 6` 得 21。

## 6. 隨堂練習

⭐ 改成輸出每一列的總和。

??? tip "只在卡住時展開"

## 7. 常見錯誤

外層 i<r，內層 j<c；兩者不可混用。
