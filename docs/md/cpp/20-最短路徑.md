# 20. Dijkstra：帶非負權重的最短路

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

兩條路邊數可能相同但通行時間不同。BFS 以每步相同成本為前提；Dijkstra 適用於邊權非負的最短路徑。

## 2. 必要規則與語法

用優先佇列維護目前最短候選距離，出列後嘗試 Relax（鬆弛）相鄰邊；發現更小距離就更新。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <functional>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>

int main() {
    int n, m;
    std::cin >> n >> m;
    std::vector<std::vector<std::pair<int,int>>> g(n);
    for (int i = 0; i < m; i++) {
        int u, v, w;
        std::cin >> u >> v >> w;
        g[u].push_back({v, w});
    }
    const long long INF = (1LL << 60);
    std::vector<long long> dist(n, INF);
    using P = std::pair<long long,int>;
    std::priority_queue<P, std::vector<P>, std::greater<P>> pq;
    dist[0] = 0;
    pq.push({0, 0});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist[v] > d + w) {
                dist[v] = d + w;
                pq.push({dist[v], v});
            }
        }
    }
    if (dist[n - 1] == INF) std::cout << -1 << "\n";
    else std::cout << dist[n - 1] << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

0→2 成本 10；0→1 成本 2、1→2 成本 3，因此較短路徑總成本 5。此例為有向圖，n≥1。

## 5. 驗證：先預測，再執行

輸入 `3 3↵0 2 10↵0 1 2↵1 2 3`，應輸出 5。

## 7. 常見錯誤

若邊權有負數，不可直接使用此版本 Dijkstra。
