# 09. Function：函式與參數

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

函式像小工具，給它輸入參數，完成計算並回傳結果。將問題拆小較易測試。

## 2. 必要規則與語法

`int square(int x)` 會收到整數 x 並回傳整數；`return` 把結果送回呼叫處。函式中的區域變數通常不能在外面直接存取。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int square(int x) {
    return x * x;
}

int main() {
    int a, b;
    std::cin >> a >> b;
    std::cout << square(a) + square(b) << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

輸入 3 4，square(3)=9、square(4)=16，相加得到 25。

## 5. 驗證：先預測，再執行

輸入 `3 4` 得 25；輸入 `0 5` 也得 25。

## 6. 隨堂練習

⭐ 寫 `int maxOfTwo(int a,int b)` 回傳較大的整數。

??? tip "只在卡住時展開"
    先寫出「輸入 → 變數如何改變 → 預期輸出」，再改寫程式並自行執行。不要只複製解答。

## 7. 常見錯誤

`cout` 是輸出，`return` 是回傳；兩者不是同一件事。
