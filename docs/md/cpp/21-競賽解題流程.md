# 21. 解題流程：從讀題到 AC

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

競賽最重要的不是語法背得快，而是能把文字題目轉成正確、高效率、可驗證的演算法。

## 2. 必要規則與語法

固定流程：讀清 I/O 與資料範圍 → 列舉邊界 → 設計最簡單正確方法 → 估計複雜度 → 實作 → 用極端測資驗證。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    int answer = 0;
    for (int i = 0; i < n; i++) {
        int x;
        std::cin >> x;
        if (x > 0) answer++;
    }
    std::cout << answer << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

題目是統計正數個數；0 不算正數，遇到 x>0 才加 1。時間 O(n)、額外空間 O(1)。

## 5. 驗證：先預測，再執行

輸入 `5↵-2 0 3 1 -1`，應輸出 2。

⭐ 不看範例重寫，並解釋每個變數代表什麼。

## 8. 常見錯誤
