# 02. 變數、整數與小數

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

變數就像有名字的置物盒；C++ 必須指定盒子裡存哪種資料。

## 2. 必要規則與語法

`int` 整數、`long long` 較大整數、`double` 小數、`char` 單一字元、`bool` 真／假。`=` 表示賦值，`7/2` 兩邊是整數，因此結果是 3。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    int apples = 3;
    double price = 12.5;
    apples = apples + 2;
    std::cout << apples << "\n";
    std::cout << apples * price << "\n";
    std::cout << 7 / 2 << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

`apples` 原本是 3，增加 2 後變 5；總價 5×12.5=62.5；整數除法 `7/2` 得 3。

## 5. 驗證：先預測，再執行

逐行應輸出 `5`、`62.5`、`3`；把最後一行改成 `7.0/2`，應得到 `3.5`。
