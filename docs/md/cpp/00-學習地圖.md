## 2. 你需要的工具

⭐ 依照 [Visual Studio Code 官方 Windows GCC／MinGW 安裝教學](https://code.visualstudio.com/docs/cpp/config-mingw)安裝 VS Code、C/C++ 擴充套件、GCC g++ 編譯器。

⭐ 在終端機執行 `g++ --version` 確認編譯器存在，然後建立 `main.cpp`。

⭐ 編譯及執行（Windows）：

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o main
./main.exe
```

> 網站是靜態教材，**沒有線上 C++ 編譯器或自動評分功能**。請在你的電腦或正式練習平台編譯程式。參賽環境、語言版本與能否攜帶資料，以報名的學校／該屆賽事公告為準。

## 3. 建議讀法

1. 先讀「核心原理」，自己說一次這個功能為什麼存在。
2. 不看執行結果，先用紙筆推測程式輸出與中間變數。
3. ⭐ 自己打一次完整範例，編譯、執行，測試不同輸入。
4. ⭐ 先試「隨堂練習」，真的卡住才開提示。
5. 隔天不看教材再寫一次；寫不出來就先複習，不急著進下一課。
