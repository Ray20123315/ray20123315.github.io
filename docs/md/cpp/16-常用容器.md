# 16. stack、queue、set、map

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

不同資料結構對不同操作有優勢：疊盤子是 stack，排隊是 queue；set 去重，map 對應鍵與值。

## 2. 必要規則與語法

stack 使用 push/top/pop（後進先出），queue 使用 push/front/pop（先進先出），set.insert 插入不重複元素，map[key] 存取值。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>
#include <queue>
#include <stack>

int main() {
    std::stack<int> s;
    std::queue<int> q;
    for (int x : {3, 5, 7}) {
        s.push(x);
        q.push(x);
    }
    std::cout << s.top() << "\n";
    std::cout << q.front() << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

放入 3、5、7，stack 最上層是 7，queue 最前端是 3。

## 5. 驗證：先預測，再執行

答案依序輸出 7、3。
