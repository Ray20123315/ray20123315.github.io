# 03. 輸入、輸出與運算子

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

競賽解題從標準輸入讀取題目測資，再透過標準輸出提交計算結果；不能自行加「請輸入」等提示文字。

## 2. 必要規則與語法

`std::cin >> a >> b` 讀兩個數；`+ - * /` 為運算，`%` 為整數取餘數；先乘除後加減，不確定時用括號。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cin >> a >> b;
    std::cout << a + b << "\n";
    std::cout << a % b << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

輸入 `17 5`，讀入 a=17、b=5。總和 22，17 除以 5 的餘數為 2。

## 5. 驗證：先預測，再執行

輸入 `17 5`，應依序輸出 `22` 和 `2`。這份範例假設 b 不等於 0。

## 6. 隨堂練習

⭐ 輸入兩個整數，輸出其乘積；再修改成輸出小數平均值。

??? tip "只在卡住時展開"
    先寫出「輸入 → 變數如何改變 → 預期輸出」，再改寫程式並自行執行。不要只複製解答。

## 7. 常見錯誤

整數除數為 0 不能執行 `/` 或 `%`；`cout` 的大小寫也不可更動。
