# 04. if、else：條件判斷

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

條件判斷就是依資料做決策，例如分數達 60 才及格。

## 2. 必要規則與語法

`==` 相等、`!=` 不等、`<=` 小於等於；`&&` 表示且，`||` 表示或。`if → else if → else` 依序判斷，符合一個分支後便不再執行後面分支。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    int score;
    std::cin >> score;
    if (score >= 90) {
        std::cout << "A\n";
    } else if (score >= 60) {
        std::cout << "Pass\n";
    } else {
        std::cout << "Retry\n";
    }
    return 0;
}
```

## 4. 用手追蹤程式

若 score=75，`score>=90` 為假，`score>=60` 為真，因此輸出 Pass。

## 5. 驗證：先預測，再執行

測試 95、75、40、60，應分別印出 A、Pass、Retry、Pass。
