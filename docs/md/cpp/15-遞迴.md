# 15. Recursion：遞迴與終止條件

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

大問題可以由較小但形式相同的問題構成；遞迴就是讓函式呼叫自己。

## 2. 必要規則與語法

每個遞迴要有 Base Case（終止條件），且呼叫的規模必須接近終止條件。回溯則是嘗試選擇、探索，再撤回。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

long long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main() {
    int n;
    std::cin >> n;
    std::cout << factorial(n) << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

factorial(4)=4×factorial(3)=4×3×2×1=24。示例限定 0≤n≤20。

## 5. 驗證：先預測，再執行

輸入 0、1、4，答案依序為 1、1、24。
