# 01. 第一支 C++ 程式

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。完全零基礎也能開始。

## 1. Core Principle（核心原理）

C++ 的原始碼需要編譯器（Compiler）轉成執行檔；寫完文字不等於已執行。

## 2. 必要規則與語法

`#include <iostream>` 載入輸入輸出工具、`int main()` 是入口、`{}` 是範圍、`std::cout` 輸出內容、`;` 結束敘述、`\n` 換行。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!\n";
    std::cout << "I can code!\n";
    return 0;
}
```

## 4. 用手追蹤程式

由 `main()` 從上而下執行，第一個 `cout` 輸出 `Hello, C++!` 並換行，第二個輸出 `I can code!`。`return 0;` 正常結束程式。

## 5. 驗證：先預測，再執行

應出現兩行 `Hello, C++!` 和 `I can code!`。
