# 14. Prefix Sum：前綴和

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

面對大量區間和查詢，每次把整段重新加總會慢；事先儲存從開頭累積到各點的總和，可快速計算任意區間。

## 2. 必要規則與語法

`prefix[0]=0`，`prefix[i+1]=prefix[i]+a[i]`，閉區間 [l,r] 的和是 `prefix[r+1]-prefix[l]`。預處理 O(n)，每次查詢 O(1)。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>
#include <vector>

int main() {
    int n, q;
    std::cin >> n >> q;
    std::vector<long long> pre(n + 1, 0);
    for (int i = 0; i < n; i++) {
        long long x;
        std::cin >> x;
        pre[i + 1] = pre[i] + x;
    }
    while (q--) {
        int l, r;
        std::cin >> l >> r;
        std::cout << pre[r + 1] - pre[l] << "\n";
    }
    return 0;
}
```

## 4. 用手追蹤程式

陣列 2 3 5 7 的 pre 為 0、2、5、10、17，查 [1,3] 得 17-2=15。

## 5. 驗證：先預測，再執行

輸入 `4 2↵2 3 5 7↵1 3↵0 0`，應輸出 15、2。
