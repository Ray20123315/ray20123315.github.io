# 08. string：處理文字

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

字串可視為連續的字元。很多題目要求計算特定字母數量、反轉字串或判斷回文。

## 2. 必要規則與語法

`cin>>s` 讀到第一個空白前；`s.size()` 是長度；`s[i]` 取得字元；字元常值寫 `'a'`，字串常值寫 `"a"`。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s;
    std::cin >> s;
    int count = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] == 'a') count++;
    }
    std::cout << count << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

`banana` 逐字檢查 b a n a n a，字母 a 有 3 個。

## 5. 驗證：先預測，再執行

輸入 banana 得 3；輸入 BBB 得 0。
