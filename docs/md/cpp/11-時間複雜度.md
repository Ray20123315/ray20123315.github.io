# 11. Time Complexity：時間複雜度

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

競賽的程式除了正確，還要能處理最大資料量。時間複雜度描述當 n 變大時工作次數如何增長。

## 2. 必要規則與語法

單次遍歷約 O(n)、雙層各跑 n 次約 O(n²)、每次砍半約 O(log n)。這是估算量級，不是保證時間。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    long long work = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) work++;
    }
    std::cout << work << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

外層 n 次，內層每次 n 次，因此工作量 n²。n=10 是 100 次，n=100 是 10000 次。

## 5. 驗證：先預測，再執行

輸入 3 得 9，輸入 10 得 100。

## 6. 隨堂練習

⭐ 比較 n=1000000 時，O(n) 與 O(n²) 的大致工作量。

??? tip "只在卡住時展開"
    先寫出「輸入 → 變數如何改變 → 預期輸出」，再改寫程式並自行執行。不要只複製解答。

## 7. 常見錯誤

程式行數少不代表速度快，迴圈數量和容器操作才重要。
