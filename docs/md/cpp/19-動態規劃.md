# 19. Dynamic Programming：動態規劃

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

當多個大問題需要相同小問題的答案，先儲存小問題結果，就不用反覆重算。

## 2. 必要規則與語法

爬樓梯每次走 1 或 2 階。定義 dp[i]：到第 i 階的方法數；dp[0]=1、dp[1]=1、dp[i]=dp[i-1]+dp[i-2]。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<long long> dp(n + 2, 0);
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    std::cout << dp[n] << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

第 3 階有三種方法：1+1+1、1+2、2+1，故 dp[3]=3。建議 n≤90 以免 long long 溢位。

## 5. 驗證：先預測，再執行

輸入 0、1、3、4，分別輸出 1、1、3、5。

## 6. 隨堂練習

⭐ 改成能一次走 1、2、3 階，推導轉移式。

??? tip "只在卡住時展開"
    先寫出「輸入 → 變數如何改變 → 預期輸出」，再改寫程式並自行執行。不要只複製解答。

## 7. 常見錯誤

DP 先定義狀態、再定義轉移和初始值，不能先背程式模板。
