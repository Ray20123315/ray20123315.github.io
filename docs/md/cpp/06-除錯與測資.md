# 06. 除錯、追蹤與測試

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

除錯不是猜錯在哪，而是拿筆記下每一步的變數，找出第一次與預期不符的地方。

## 2. 必要規則與語法

區分 Compile Error（無法編譯）、Runtime Error（執行中錯誤）、Wrong Answer（答案錯誤）。使用一般測資、最小測資、最大測資與邊界測資。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    int count = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) count++;
    }
    std::cout << count << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

n=5 時，i 依序為 1、2、3、4、5，僅 2 和 4 使 count 加 1，答案 2。

## 5. 驗證：先預測，再執行

輸入 1、2、5、6，答案依序 0、1、2、3。

## 6. 隨堂練習

⭐ 刻意將 `i<=n` 改成 `i<n`，找出第一個造成錯誤的測資。

??? tip "只在卡住時展開"
    先寫出「輸入 → 變數如何改變 → 預期輸出」，再改寫程式並自行執行。不要只複製解答。

## 7. 常見錯誤

編譯成功不代表解題正確；要靠測試才能驗證邏輯。
