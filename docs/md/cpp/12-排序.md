# 12. Sorting：排序

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

排序把資料整理成順序，方便搜尋、排程或貪心演算法。

## 2. 必要規則與語法

`std::sort(a.begin(),a.end())` 預設由小到大，需 `#include <algorithm>`；一般比較排序時間約 O(n log n)。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<int> a(n);
    for (int &x : a) std::cin >> x;
    std::sort(a.begin(), a.end());
    for (int x : a) std::cout << x << " ";
    std::cout << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

8、3、8、1、4 排序後得到 1、3、4、8、8；重複值不會消失。

## 5. 驗證：先預測，再執行

測試含負數、重複值和已排序資料。

## 6. 隨堂練習

⭐ 將排序改成由大到小，查閱 `std::greater<int>()`。

??? tip "只在卡住時展開"
    先寫出「輸入 → 變數如何改變 → 預期輸出」，再改寫程式並自行執行。不要只複製解答。

## 7. 常見錯誤

sort 會改動原本 vector 的順序，需要原順序時要先複製。
