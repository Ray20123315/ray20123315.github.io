# 23. 競賽模擬測驗（自編）

這三題是**自編練習，不是正式考古題**，也不代表任何地區、學校或年度的題數與配分。建議自主限時 90 分鐘，使用 C++17，不看教材獨立完成。

## 第 1 題：進出貨統計

初始庫存為 0。輸入 n（1≤n≤100000）和 n 個庫存增減 x（-100000≤x≤100000），輸出最後庫存與過程中最高庫存（初始庫存 0 也算）。

```text
輸入
5
5 -2 4 -10 6
輸出
3 7
```

??? tip "提示"
    將目前庫存的型別設為 long long，逐筆更新，再和最高紀錄比較。

## 第 2 題：兩數湊目標

輸入 n（2≤n≤200000）、K（-2×10⁹≤K≤2×10⁹）、n 個整數（每個值在 ±10⁹）。判定是否存在**不同索引的兩個數**相加等於 K。存在輸出 YES，否則 NO。

```text
輸入
5 11
2 7 4 9 1
輸出
YES
```

??? tip "提示"
    排序後用左右指標。兩數和太小就把左邊指標右移；太大則把右邊指標左移。和使用 long long。

## 第 3 題：迷宮最短路

輸入 n、m（1≤n,m≤500）和 n 行長度 m 的地圖。S 起點、T 終點、# 牆、. 可走，每次只能上下左右走一格。地圖恰有一個 S 與 T。輸出到 T 的最少步數，不可達則 -1。

```text
輸入
3 4
S...
.##.
...T
輸出
5
```

??? tip "提示"
    每格視為圖節點，使用 BFS，起點距離 0，其餘為 -1；訪問相鄰的可通行格後記錄距離。

## 交卷前的檢查

1. 沒有額外印「請輸入」等提示。
2. 已測試最小資料、邊界、不可達及重複值情境。
3. 注意 0-based／1-based 與陣列長度。
4. 大數運算使用合適的資料型別。
5. 估計最大資料量的時間與記憶體需求。
