# 13. Binary Search：二分搜尋

**本課目標：** 理解本節核心觀念、獨立執行範例，並完成隨堂題。建議先完成前一課。

## 1. Core Principle（核心原理）

字典按順序排列，翻到中間就能淘汰一半不可能的範圍。二分搜尋利用的就是「有序」或「單調」性。

## 2. 必要規則與語法

`left`、`right` 管理候選範圍，依 `mid` 值與目標比較，把不可能的一半移除；時間 O(log n)。

## 3. 可編譯的完整 C++17 範例

```cpp
#include <iostream>
#include <vector>

int main() {
    int n, target;
    std::cin >> n >> target;
    std::vector<int> a(n);
    for (int &x : a) std::cin >> x;
    int left = 0, right = n - 1, answer = -1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == target) {
            answer = mid;
            break;
        }
        if (a[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    std::cout << answer << "\n";
    return 0;
}
```

## 4. 用手追蹤程式

已排序 1 3 5 7 9，找 7；先看中間 5，往右找到索引 3。

## 5. 驗證：先預測，再執行

輸入 `5 7↵1 3 5 7 9` 得 3；找不到應得 -1。
